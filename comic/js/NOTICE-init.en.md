# init.js provenance

English | [简体中文](NOTICE-init.md)

`init.js` in this directory was written from the behaviour specification in [docs/SENDMESSAGE-SPEC.en.md](../../docs/SENDMESSAGE-SPEC.en.md). The author did not open the official `init_js.dart` or `init.js` while writing it. The specification lists every global name, method name, message field and quirk that scripts depend on.

Interface names (globals, methods, message fields, constructor parameter names) are required for compatibility with existing ComicSource scripts and are not creative expression. The code that wraps them is original.

`video-prelude.js` is a VeneraCat extension that adds the `VideoSource` base class; it is not part of the official interface.
