# 服务插件契约

[English](./SERVICE-PLUGINS.en.md) | 简体中文

Trakt、TMDB、Bangumi 这类按需服务在统一合集里是**服务条目**，不是漫画源，也不是视频源。它们共享一套契约：Core 负责校验与授权，客户端负责网络、凭据、持久化和界面。

本文件描述第一版契约。它只覆盖**清单、权限、模块调用**；界面、安装入口与账号流程由各端自行实现。

## 清单

服务条目带一份清单。Core 的 `service` 包解析并校验它：

| 字段 | 含义 | 规则 |
| --- | --- | --- |
| `id` | 身份 | 小写字母、数字、`-`、`.`；同时段内唯一 |
| `name` | 显示名 | 非空 |
| `version` | 版本 | 非空 |
| `kind` | 类型 | 固定为 `service.js` |
| `entry` | 入口文件 | 包内相对路径 |
| `permissions` | 申请的权限 | 只能取已知权限，不可重复 |

校验刻意严格：

- **未知字段直接拒绝。** 服务以为自己申请了某个能力、宿主却忽略它，会让它在更小的沙箱里运行。
- **`entry` 必须是包内相对路径。** 绝对路径、`../`、`./` 与反斜杠都拒绝，避免读到包外的文件。
- **未知权限不能出现。** 宿主与服务的“允许清单”若对不上，就无法判断谁是对的。

## 权限

| 权限 | 含义 |
| --- | --- |
| `network` | 通过宿主发起 HTTP 请求 |
| `storage` | 通过宿主保存少量键值 |
| `secrets` | 读取用户为该服务填写的账号值 |

生效权限 = **服务申请的 ∩ 宿主允许的**。宿主可以少给：少给的部分在界面上应显示为被拒绝，而不是悄悄按更小的能力运行。`Grants.Effective` 给出当前生效项，`Grants.Denied` 给出被拒项。

宿主授出自己不认识的权限时会被拒绝，而不是忽略。

## 模块契约

服务是一个 JavaScript 模块，导出 `handle`：

```js
export function handle(method, payload) {
  if (method === 'ping') return { ok: true };
  return null;
}
```

- `method` 是服务自己的方法名，例如 `trakt.sync`、`tmdb.search`。
- `payload` 是请求的原始 JSON 文本；服务自己解析。
- 返回值会被序列化为 JSON；`null` 表示没有结果。

宿主侧的调用入口是 `service.Runtime`：加载一次，之后按方法串行调用。调用串行化，因为一个运行时只有一个执行线程。

## 宿主能力

模块通过全局函数访问宿主，全部按权限把关。被拒绝时返回明确错误（写明缺哪个权限），而不是 `undefined is not a function`：

| 全局 | 需要的权限 | 行为 |
| --- | --- | --- |
| `fetch(url)` | `network` | 同步取回响应正文 |
| `storageGet(key)` | `storage` | 读一个键；没有则 `null` |
| `storageSet(key, value)` | `storage` | 写一个键 |
| `secret(key)` | `secrets` | 读一个账号值 |
| `log(level, message)` | 无 | 服务自己的日志 |

宿主未实现某项能力时（例如没有网络），调用返回“本宿主没有该能力”，与“没有权限”是两回事。

## 尚未实现

- 异步 handler 与 `await`：第一版只支持同步 handler，`fetch` 是同步阻塞调用。
- 模块导入与依赖安装：服务只能使用自身包内文件。
- 安装、升级与界面：Core 侧只有契约，两端尚未接入。
- 权限提示：客户端应显示申请与被拒的权限，目前尚无统一界面。

## 与漫画源、视频源的关系

服务不是漫画源，也不是视频源：它不产出漫画或视频条目，只提供同步、鉴权与元数据。Core 里两者分别是 `comic/js` 与 `video` 包，三者不共享注册表。
